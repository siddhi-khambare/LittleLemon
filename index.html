Little Lemon

Chicago

Little Lemon is a charming neighborhood bistro that serves simple food and classic cocktails in a lively but casual environment. The restaurant features a locally-sourced menu with daily specials.

Founded by brothers Mario and Adrian, Little Lemon combines rustic Mediterranean traditions with contemporary cooking styles to bring an unforgettable dining experience to downtown Chicago.

Django REST Framework Endpoints

Coursera Back-End Developer Capstone Endpoints

1. Menu API

CRUD operations for restaurant dishes and pricing.

  • GET/POST /api/menu/
  • GET/PUT/DEL /api/menu/<id>/

2. Booking API

Table reservations with customer details and associated user.

  • GET/POST /api/booking/
  • GET/PUT/DEL /api/booking/<id>/

3. Auth & Token API

Customer registration and token-based authentication.

  • POST /api/register/
  • POST /api/api-token-auth/
